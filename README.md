# Site do Colégio Nossa Senhora do Carmo

Prévia de site institucional para o Colégio Nossa Senhora do Carmo (Barra dos Coqueiros/SE), feita para apresentação da proposta.

- `index.html`: página única, responsiva, com o logo embutido.
- Fotos e alguns textos são provisórios e serão trocados pelo material da escola.
